## How to install

See `README.txt` / `README.md` in the download ZIP.

## How to upgrade from version 21 to version 21.1

If you are still on version **20 or older**, complete [Version 21](./21.md) first, then continue here.

1. Download [PHP SDK v21.1](../../releases/swiss-parks-php-sdk-21.1.zip)
2. Backup all of your current API files
3. Backup your MySQL database
4. Replace the following files and folders in `/{PATH-TO-YOUR-API-FOLDER}/`
   - `/autoload.php`
   - `/classes`
5. Execute the migration script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/migrate.php`
6. Execute the cron script and force import of all offers: `/{PATH-TO-YOUR-API-FOLDER}/scripts/force_update.php`
7. Check overviews, maps and detail pages.
8. Check the browser console against JS errors.
9. Check your log file and test the complete website.
