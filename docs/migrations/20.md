# Version 20

Released: **June 18, 2024**

Package: [`releases/swiss-parks-php-sdk-20.zip`](../../releases/swiss-parks-php-sdk-20.zip)

## What's new

New in this version:

- Project improvements:
  - Import and display of new project fields and duration (month)
  - Fields of activity synchronization
- Webshop improvements:
  - Import and display of new article fields
- Overview and filter:
  - Group by one-day events and showing multiple starting times as one event.
  - List hints as all other entries (no more listing on the top)
  - Change starting date display if filter is set or event has already started.
  - New filter by accessibility with new tag `__FILTER_ACCESSIBILITIES__`
  - New filter option `hide_accessibility_filter` (enable if the accessibility filter should be hidden)
- Map:
  - New map option `do_not_group_categories_in_legend` (enable if categories should not be grouped in the category menu)
- Misc:
  - Bigger max length for offer i18n fields
  - Synchronization of data returns new JSON file with status and message
  - Improvements for PHP 8.2 stability

## How to upgrade from version 19 to version 20

1. Download [PHP SDK v20](../../releases/swiss-parks-php-sdk-20.zip)
2. Backup all of your current API files
3. Backup your MySQL database
4. Replace the following files and folders in `/{PATH-TO-YOUR-API-FOLDER}/`
   - `/autoload.php`
   - `/classes`
   - `/helpers`
   - `/language`
   - `/template/standard`
5. Change the path of the linked CSS and JS files from `/api-17/` to `/api-20/`
6. Execute the migration script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/migrate.php`
7. Execute the cron script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/cron.php`
8. Check overviews, maps and detail pages.
9. Check the browser console against JS errors.
10. Check your log file and test the complete website.
