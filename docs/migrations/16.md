# Version 16

Released: **July 26, 2022**

Package: [`releases/swiss-parks-php-sdk-16.zip`](../../releases/swiss-parks-php-sdk-16.zip)

## What's new

New in this version:

- New products online shop integration
- New text lengths for language dependent fields
- New maximal amount of images per offer (up to 15 images)
- Display of the route conditions (overview, detail, map)
- Accessibility improvements (for screen readers)
- Improved API synchronization

## How to install

See `README.txt` / `README.md` in the download ZIP.

## How to upgrade from version 15 to version 16

1. Download [PHP SDK v16](../../releases/swiss-parks-php-sdk-16.zip)
2. Backup all of your current API files
3. Backup your MySQL database
4. Replace the following files and folders in `/{PATH-TO-YOUR-API-FOLDER}/`
   - `/autoload.php`
   - `/classes`
   - `/language`
5. Execute the migration script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/migrate.php`
6. Execute the cron script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/force_update.php`
7. Check and format the filter icons (there have been changes for accessibility reasons)
8. Check the overview and detail pages
9. Check your log file and test the complete website
