# Version 21

Released: **May 6, 2025**

Package: [`releases/swiss-parks-php-sdk-21.zip`](../../releases/swiss-parks-php-sdk-21.zip)

## What's new

New in this version:

- MySQL database compatibility for `sql_mode: only_full_group_by`
- Import, display and filter of municipality informations with new configuration option `show_municipality_filter` and new filter template tag `__FILTER_MUNICIPALITIES__`
- New CSS and JS paths: Preparations for the complete removal of the jQuery Library (coming in future versions)
- Extended import of large data sets
- Removed project and bookable offer fields: Place; Responsible contact
- Import and handling of research as projects (removed research template placeholders `__OFFER_RESEARCH__` and `__OFFER_RESEARCH_DETAIL__`)
- Overviews: Hide date for research offers
- Improved session handling
- Misc text changes

## How to upgrade from version 20 to version 21

1. Download [PHP SDK v21](../../releases/swiss-parks-php-sdk-21.zip)
2. Backup all of your current API files
3. Backup your MySQL database
4. Replace the following files and folders in `/{PATH-TO-YOUR-API-FOLDER}/`
   - `/autoload.php`
   - `/classes`
   - `/helpers`
   - `/language`
   - `/template/standard`
5. Add new configuration option `$config['show_municipality_filter'] = true;` to your `config.php` (line 144)
6. Change the path of the linked jQuery and jQuery UI files (see `example.php`)
7. Change your template, **remove** loading the following CSS and JavaScripts (see `example.php`):
   - https://angebote.paerke.ch/api/lib/api-20/api.css
   - https://angebote.paerke.ch/api/lib/api-20/[LANGUAGE].min.js
   - https://angebote.paerke.ch/api/lib/api-20/ParkApp.min.js
8. Change your template, **add** loading the following CSS and JavaScripts (see `example.php`):
   - https://angebote.paerke.ch/assets/dist/v21/css/parks.min.css
   - https://angebote.paerke.ch/assets/dist/v21/parks.min.js
9. Add new filter template tag `__FILTER_MUNICIPALITIES__` to your filter template.
10. Remove research template placeholders `__OFFER_RESEARCH__` and `__OFFER_RESEARCH_DETAIL__` from your detail template.
11. Execute the migration script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/migrate.php`
12. Execute the cron script and force import of all offers: `/{PATH-TO-YOUR-API-FOLDER}/scripts/force_update.php`
13. Check overviews, maps and detail pages.
14. Check the browser console against JS errors.
15. Check your log file and test the complete website.
