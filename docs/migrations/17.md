# Version 17

Released: **November 8, 2022**

Package: [`releases/swiss-parks-php-sdk-17.zip`](../../releases/swiss-parks-php-sdk-17.zip)

## What's new

In version 17, jQuery and jQuery UI have been updated to their latest version.

- jQuery v3.6.1
- jQuery UI v1.13.2

## How to install

See `README.txt` / `README.md` in the download ZIP.

## How to upgrade from version 16 to version 17

1. Download [PHP SDK v17](../../releases/swiss-parks-php-sdk-17.zip)
2. Backup all of your current API files
3. See `example.php` and replace CSS path of `api.css`
4. See `example.php` and replace JS path of the language file `de.js`, `fr.js`, `it.js` or `en.js`
5. See `example.php` and replace JS path of jQuery (`jquery.min.js`)
6. See `example.php` and replace JS path of jQuery UI (`jquery-ui.min.js`)
7. See `example.php` and replace JS path of `ParkApp.min.js`
8. Replace the following files and folders in `/{PATH-TO-YOUR-API-FOLDER}/`
   - `/autoload.php`
   - `/classes`
   - `/language`
9. Execute the migration script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/migrate.php`
10. Test every part of your website and solve potential JavaScript problems or conflicts with the new jQuery and jQuery UI versions (check browser console!)
