# Version 19

Released: **April 11, 2023**

Package: [`releases/swiss-parks-php-sdk-19.zip`](../../releases/swiss-parks-php-sdk-19.zip)

## What's new

New in this version:

- New template placeholder `__OFFER_ROUTE_LIST__` to display the routes in the vicinity

## How to install

See `README.txt` / `README.md` in the download ZIP.

## How to upgrade from version 18 to version 19

1. Download [PHP SDK v19](../../releases/swiss-parks-php-sdk-19.zip)
2. Backup all of your current API files
3. Backup your MySQL database
4. Replace the following files and folders in `/{PATH-TO-YOUR-API-FOLDER}/`
   - `/autoload.php`
   - `/classes`
   - `/language`
   - `/template/standard`
5. Execute the migration script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/migrate.php`
6. Include the new template placeholder `__OFFER_ROUTE_LIST__` into your detail template. Compare your `detail.tpl` file with the API `standard/detail.tpl` file and include the new placeholder.
7. Check offer detail page with linked routes informations. The information will be taken from the POI list of an offer.
8. Check your log file and test the complete website.
