# Version 15

Released: **February 21, 2022**

Package: [`releases/swiss-parks-php-sdk-15.zip`](../../releases/swiss-parks-php-sdk-15.zip)

## What's new

New in this version:

- Import internal informations from offer types projects and research
- New detail template placeholder `OFFER_INTERNAL_INFOS` to display internal informations on detail page.

## How to install

See `README.txt` / `README.md` in the download ZIP.

## How to upgrade from version 14 to version 15

1. Download [PHP SDK v15](../../releases/swiss-parks-php-sdk-15.zip)
2. Backup all of your current API files
3. Backup your MySQL database
4. Replace the following files and folders in `/{PATH-TO-YOUR-API-FOLDER}/`
   - `/autoload.php`
   - `/classes`
   - `/language`
   - Upload new file `/scripts/force_update.php`
5. Execute the migration script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/migrate.php`
6. Execute the cron script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/force_update.php`
7. Add new placeholder `__OFFER_INTERNAL_INFOS__` to your detail template, if you want to display internal informations from projects or research offers.
8. Check your log file and test your website.
