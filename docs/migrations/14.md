## How to upgrade from version 13 to version 14

1. Download [PHP SDK v14](../../releases/swiss-parks-php-sdk-14.zip)
2. Backup all of your current API files
3. Replace the following files and folders in `/{PATH-TO-YOUR-API-FOLDER}/`
   - `/autoload.php`
   - `/classes`
4. Execute the migration script: `/{PATH-TO-YOUR-API-FOLDER}/scripts/migrate.php`
5. Check your log file and test your website.
